# MineLatino Cosmetics 0.1.0-alpha.35

- Añade un editor individual y ordenado para cada módulo del HUD.
- Permite mostrar u ocultar de forma independiente el fondo y el borde.
- Añade controles de opacidad entre 0 % y 100 % y tamaño entre 50 % y 200 %.
- Conserva y migra automáticamente las configuraciones `hud.json` anteriores.
- Corrige el ancho y centrado de los porcentajes de armadura, incluido `100 %`, en formato horizontal y vertical.
- Mantiene la interfaz utilizable en resoluciones pequeñas con filas compactas y botones de navegación fijos.
