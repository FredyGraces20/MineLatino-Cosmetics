# MineLatino Cosmetics 0.1.0-alpha.21

- Añade cosméticos de tipo **Skin** mediante paquetes ZIP abiertos de MineLatino.
- Renderiza modelos Bedrock/Blockbench completos con jerarquía de huesos, texturas y animaciones.
- Añade ruleta de emotes, tecla configurable y sincronización entre jugadores.
- Incluye caché segura, validación de paquetes y reemplazo del modelo del jugador.
- Mantiene compatibilidad con Fabric y Forge para Minecraft 1.21.4 y 1.21.11.

El paquete del personaje debe contener `main.json`, una textura PNG y, opcionalmente, archivos `*.animation.json`. Los archivos `.ysm` no se cargan directamente.
