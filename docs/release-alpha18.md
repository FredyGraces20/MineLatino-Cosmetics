# MineLatino Cosmetics 0.1.0-alpha.18

- Añade cuentas MineLatino para jugadores premium y no premium.
- La propiedad y el equipamiento usan un ID interno, no el nick.
- El launcher entrega al mod un token de juego temporal sin compartir la contraseña.
- Los jugadores con el mod ven los cosméticos mediante la presencia de la cuenta activa.
- El panel web permite buscar, editar, suspender, reactivar y eliminar cuentas.
- Mantiene compatibilidad con los cosméticos premium existentes guardados por UUID.
