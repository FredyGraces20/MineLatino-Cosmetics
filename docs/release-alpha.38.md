# MineLatino Cosmetics 0.1.0-alpha.38

- Corrige la corrupción visual del Armario al mostrar cosméticos con texturas atlas.
- Las tarjetas ya no dibujan el PNG del modelo como si fuera una miniatura completa.
- Cada producto muestra una insignia 3D delimitada con estado de carga; el modelo y sus
  materiales reales se renderizan únicamente dentro del visor 3D recortado.
- Añade el backend, panel y autenticación restringida necesarios para administrar y
  contabilizar tiempo de AFK Farm por cuenta MineLatino.
- Aplicado a Fabric y Forge para Minecraft 1.21.4 y 1.21.11.

El cliente no contiene claves administrativas ni puede declarar su propio consumo.
