# MineLatino Cosmetics 0.1.0-alpha.33

- Reemplaza **Player Reporting** en el menú de pausa por **Personalizar**.
- Añade un editor visual y arrastrable del HUD, guardado por instalación.
- Módulos configurables: FPS, coordenadas, CPS izquierdo/derecho, durabilidad de armadura y efectos activos.
- Mantiene la preferencia del jugador después de colocar o desactivar cada módulo.
- Añade integración de render y captura de clics compatible con Fabric y Forge en Minecraft 1.21.4 y 1.21.11.
