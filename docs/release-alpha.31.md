# MineLatino Cosmetics 0.1.0-alpha.31

- Corrige la conversión vertical de mascotas entre el editor web y el renderer de Minecraft.
- Mantiene las mascotas en un anclaje independiente arriba y al costado del jugador, fuera del recorrido de la mano.
- Incluye Fabric y Forge para Minecraft 1.21.4 y 1.21.11.
