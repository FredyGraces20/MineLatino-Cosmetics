# MineLatino Cosmetics 0.1.0-alpha.34

- Nuevo estilo glass/carbón para los módulos y controles del editor HUD.
- Añade brújula dinámica con puntos cardinales, marcas y grados, sin barra de color superior.
- Añade visualizador de W/A/S/D, clic izquierdo, clic derecho y salto.
- Permite alternar entre disposición horizontal y vertical en coordenadas, CPS, armadura y efectos.
- Permite elegir individualmente seis colores/transparencias de fondo para cada módulo.
- El módulo de efectos queda oculto durante el juego cuando el jugador no tiene efectos activos.
- Migra automáticamente la configuración creada por versiones anteriores.
