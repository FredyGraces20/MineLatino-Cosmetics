# MineLatino Cosmetics alpha.10

- El editor web abre el slot real del cosmético seleccionado; una mochila ya no guarda accidentalmente su transformación como `head`.
- El botón **Actualizar** del armario fuerza también la descarga de posición, rotación y escala desde la API.
- El registro de diagnóstico informa el estado, cantidad y antigüedad de las transformaciones remotas.
- Compatible con Fabric 1.21.4, Forge 1.21.4 y Fabric 1.21.11.
