# MineLatino Cosmetics 0.1.0-alpha.28

- Las mascotas aceptan proyectos `.bbmodel` directamente desde el panel web.
- El servicio convierte cubos, jerarquías, pivotes, rotaciones y UVs al formato compartido por launcher y mod.
- Las texturas PNG incrustadas se importan automáticamente y los clips numéricos quedan disponibles como animación de mascota.
- El formato JSON Java anterior continúa siendo compatible.
